# Как перенести проект в Cloud Codex

## Что отправить

Отправить в новый облачный чат один последний ZIP с меткой `ti2026-cloud-handoff`. Этот архив содержит весь рабочий проект, handoff-документы, результаты, код, контрольные суммы и 34 скриншота. Старый архив `ti2026-pre-final` нужен только как резервная контрольная точка и не является предпочтительным входом для нового чата.

## Первое сообщение

После загрузки ZIP вставить содержимое `handoff/CLOUD_CODEX_INITIAL_PROMPT.md` одним сообщением. Новый чат должен сначала распаковать архив и прочитать `handoff/CLOUD_CODEX_START_HERE.md`, а уже затем продолжать задачи из `handoff/task_board.csv`.

## Если состояние Dota 2 изменилось после архива

В том же первом сообщении приложить свежий скриншот и написать число оставшихся жетонов. Новый скриншот имеет приоритет над `analysis/current_fantasy_state.json` и `handoff/screenshots/034-630c2d55-1677-48b0-9b82-2a3ff6d1176f.png` только в части видимого текущего состояния интерфейса.

## Что новый чат не должен делать

- Не начинать шестимесячный сбор данных заново без найденной ошибки во входах.
- Не считать Core/Support суммой: клиент Dota 2 подтверждает арифметическое среднее.
- Не считать шестую серию гарантированной для всех команд.
- Не обещать попадание в top-100 или top-1500 как гарантированный результат.
- Не советовать действие, которого нет среди трёх кнопок на свежем скриншоте.

## Когда перенос считается успешным

Новый чат подтверждает, что прочитал handoff, называет текущий состав, шесть жетонов, три доступных действия, stable/upside составы и начинает с T1 из `handoff/task_board.csv` либо объясняет, почему сначала требуется синхронизация нового скриншота.
