## Критическое правило Fantasy 2026

Первичный токен клиента `DOTA_FantasyCraftHelp_ScoringDetails2026` доказывает:

1. каждый игрок считается отдельно на карте;
2. для Core и Support счёт двух игроков роли **усредняется**, а не суммируется;
3. результат серии — сумма двух лучших карт;
4. результат периода — лучшая серия роли.

Не возвращать старую ошибочную правку `sum` из первого критического аудита.
